[Autumn](https://useautumn.com) एक ओपन-सोर्स लेयर है जो Stripe और आपकी एप्लिकेशन के बीच में है, जो आपको कोड की कुछ पंक्तियों के साथ कोई भी मूल्य निर्धारण मॉडल बनाने और एम्बेड करने की अनुमति देता है। Autumn पर आप निर्माण कर सकते हैं:
- सब्सक्रिप्शन
- क्रेडिट सिस्टम और टॉप अप
- उपयोग-आधारित मॉडल और ओवरेज
- बड़े ग्राहकों के लिए कस्टम प्लान

यह सब बिना वेबहुक, अपग्रेड/डाउनग्रेड, रद्दीकरण या भुगतान विफलताओं को संभाले।


## शुरुआत करना

**क्लाउड**: Autumn का उपयोग शुरू करने का सबसे तेज़ तरीका हमारी [क्लाउड सेवा](https://app.useautumn.com) के माध्यम से है।

**स्व-होस्टेड**: यदि आप Autumn को स्व-होस्ट करना चाहते हैं:

1. सुनिश्चित करें कि आपके पास `bun` इंस्टॉल है
2. प्रोजेक्ट निर्भरताओं को इंस्टॉल करें
```bash
bun install
```
3. हमारी सेटअप स्क्रिप्ट चलाएं:
```bash
bun setup
```

4. अपने postgres DB में प्रासंगिक टेबल जेनरेट करें
```bash
bun db:generate && bun db:migrate
```

5. Autumn चलाएं:

Windows के लिए
```bash
docker compose -f docker-compose.dev.yml up
```

Mac/Linux के लिए:
 ```bash
docker compose -f docker-compose.unix.yml up
```

बस इतना ही! आपको `http://localhost:3000` पर Autumn डैशबोर्ड दिखाई देना चाहिए।

> ⚠️ लॉग इन करने के लिए, साइन इन पेज पर एक ईमेल दर्ज करें, और एक OTP आपके कंसोल/टर्मिनल में दिखाई देना चाहिए। सामान्य रूप से, हम OTP ईमेल करने के लिए Resend या Google OAuth का उपयोग करते हैं -- इन्हें `server/.env` में अपने क्रेडेंशियल प्रदान करके सेटअप किया जा सकता है

> ℹ️ हमारी सेटअप स्क्रिप्ट आवश्यक env vars और (वैकल्पिक रूप से) एक Supabase इंस्टेंस को इनिशियलाइज़ करती है। यदि आप अपने स्वयं के Postgres इंस्टेंस का उपयोग करना चाहते हैं, तो आप ऐसा कर सकते हैं -- बस `server/.env` में `DATABASE_URL` env वेरिएबल में कनेक्शन स्ट्रिंग पेस्ट करें

## समस्या निवारण

यदि पहले से चलाने के बाद `bun setup` को फिर से चलाते समय आपको `SyntaxError: Unexpected end of JSON input` त्रुटि का सामना करना पड़ता है, तो आपको पहले अपने डेटाबेस टेबल को साफ़ करने की आवश्यकता हो सकती है। यह एक [ज्ञात समस्या](https://github.com/drizzle-team/drizzle-orm/issues/4529) है जो डेटाबेस माइग्रेशन को कई बार चलाने पर हो सकती है।

इसे हल करने के लिए:

1. अपने डेटाबेस से कनेक्ट करें
2. सभी मौजूदा टेबल ड्रॉप करें
3. सेटअप स्क्रिप्ट को फिर से चलाएं


## Autumn क्यों

**1️⃣ बिलिंग इंफ्रास्ट्रक्चर तेज़ी से जटिल हो जाता है**

केवल भुगतान से अधिक: यह अनुमति प्रबंधन, मीटरिंग, cron jobs के साथ उपयोग सीमाएं बनाना, और इसे अपग्रेड, डाउनग्रेड, रद्दीकरण और विफल भुगतान स्थितियों से जोड़ना है। Race conditions, edge cases और अन्य बग आपको धीमा कर देंगे।

**2️⃣ बिलिंग और ऐप लॉजिक को अलग होना चाहिए**

बढ़ती कंपनियां अक्सर मूल्य निर्धारण पर iterate करती हैं: कीमतें बढ़ाना, क्रेडिट के साथ प्रयोग करना या एक नई सुविधा के लिए शुल्क लेना। DB migrations, in-app flows को फिर से बनाना, कस्टम मूल्य निर्धारण के लिए आंतरिक डैशबोर्ड और पुराने मूल्य निर्धारण पर उपयोगकर्ताओं को grandfathering करना एक दुःस्वप्न है।


## यह कैसे काम करता है
सबसे पहले, डैशबोर्ड पर अपने उत्पाद और योजनाएं बनाएं। हम **किसी भी** मूल्य निर्धारण मॉडल का समर्थन करते हैं। कुछ लोकप्रिय जो हमने देखे हैं उनमें शामिल हैं:

1. **उपयोग और ओवरेज** ⚡: रियल-टाइम उपयोग सीमाएं सेट करें और चुनें कि वे कब रीसेट हों। यदि उपयोगकर्ता सीमा से अधिक जाते हैं तो उन्हें शुल्क लें।
2. **क्रेडिट** 💰: उपयोगकर्ता मौद्रिक या मनमाने क्रेडिट का उपयोग कर सकते हैं जिनसे कई सुविधाएं आकर्षित हो सकती हैं
3. **सीट-आधारित प्रति-सीट सीमाओं के साथ** 👥: ग्राहकों को उनके उपयोगकर्ताओं (या अन्य entities) के लिए बिल करें
4. **अग्रिम भुगतान** 💳: उपयोगकर्ताओं को एक सुविधा की एक निश्चित मात्रा अग्रिम में खरीदने दें, जो समय के साथ उपयोग की जाती है


इसके बाद, आपकी सभी बिलिंग लॉजिक को केवल 3 फ़ंक्शन के माध्यम से लागू किया जा सकता है:

1. `/attach`: सभी खरीद प्रवाह के लिए एक फ़ंक्शन कॉल। हम एक Stripe Checkout URL वापस करते हैं, या एक अपग्रेड/डाउनग्रेड को संभालते हैं।

```tsx
const { attach } = useAutumn();
<button
  onClick={async () => {
    await attach({ productId: "pro" });
  }}
>
  Pro में अपग्रेड करें
</button>
```

2. `/check`: जांचें कि क्या किसी ग्राहक के पास किसी उत्पाद, सुविधा या शेष उपयोग तक पहुंच है।
```ts
const { check } = useAutumn();

const { data } = await check({ featureId: "ai_tokens" })

!data.allowed && alert("AI सीमा पहुंच गई")
```

3. `/track`: जब कोई ग्राहक उपयोग-आधारित सुविधा का उपयोग करता है, तो एक उपयोग इवेंट रिकॉर्ड करें।

```ts
const { track } = useAutumn();

await track({
  featureId: "ai_tokens",
  value: 1312
})
```
