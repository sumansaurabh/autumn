[Autumn](https://useautumn.com) Stripe और आपके एप्लिकेशन के बीच एक ओपन-सोर्स लेयर है, जो आपको कुछ लाइनों के कोड के साथ कोई भी प्राइसिंग मॉडल बनाने और एम्बेड करने की अनुमति देता है। Autumn पर आप निम्न बना सकते हैं:
- सब्सक्रिप्शन
- क्रेडिट सिस्टम और टॉप अप
- उपयोग-आधारित मॉडल और ओवरएज
- बड़े ग्राहकों के लिए कस्टम प्लान

यह सब वेबहुक, अपग्रेड/डाउनग्रेड, कैंसिलेशन या पेमेंट फेल्योर को हैंडल किए बिना।


## शुरुआत करें

**क्लाउड**: Autumn का उपयोग शुरू करने का सबसे तेज़ तरीका हमारी [क्लाउड सेवा](https://app.useautumn.com) के माध्यम से है।

**सेल्फ होस्टेड**: यदि आप Autumn को सेल्फ-होस्ट करना चाहते हैं:

1. सुनिश्चित करें कि आपके पास `bun` इंस्टॉल है
2. प्रोजेक्ट डिपेंडेंसी इंस्टॉल करें
```bash
bun install
```
3. हमारी सेटअप स्क्रिप्ट चलाएं:
```bash
bun setup
```

4. अपने PostgreSQL DB में संबंधित टेबल जेनरेट करें
```bash
bun db:generate && bun db:migrate
```

5. Autumn चलाएं:

Windows के लिए
```bash
docker compose -f docker-compose.dev.yml up
```

Mac/Linux के लिए:
 ```bash
docker compose -f docker-compose.unix.yml up
```

बस! आपको `http://localhost:3000` पर Autumn डैशबोर्ड दिखाई देना चाहिए।

> ⚠️ लॉग इन करने के लिए, साइन इन पेज पर एक ईमेल दर्ज करें, और एक OTP आपके कंसोल / टर्मिनल में दिखाई देगा। आम तौर पर, हम OTP को ईमेल करने के लिए Resend या Google OAuth का उपयोग करते हैं -- इन्हें `server/.env` में अपने क्रेडेंशियल्स प्रदान करके सेट किया जा सकता है।

> ℹ️ हमारी सेटअप स्क्रिप्ट आवश्यक env vars और (वैकल्पिक रूप से) एक Supabase इंस्टेंस को इनिशियलाइज़ करती है। यदि आप अपने खुद के Postgres इंस्टेंस का उपयोग करना चाहते हैं, तो आप ऐसा कर सकते हैं -- बस `server/.env` में `DATABASE_URL` env वेरिएबल में कनेक्शन स्ट्रिंग पेस्ट करें।

## समस्या निवारण

यदि पहले से चलाने के बाद फिर से `bun setup` चलाते समय आपको `SyntaxError: Unexpected end of JSON input` एरर का सामना करना पड़ता है, तो आपको पहले अपने डेटाबेस टेबल्स को साफ़ करने की आवश्यकता हो सकती है। यह एक [ज्ञात समस्या](https://github.com/drizzle-team/drizzle-orm/issues/4529) है जो डेटाबेस माइग्रेशन को कई बार चलाने पर हो सकती है।

इसे हल करने के लिए:

1. अपने डेटाबेस से कनेक्ट करें
2. सभी मौजूदा टेबल्स ड्रॉप करें
3. सेटअप स्क्रिप्ट को फिर से चलाएं


## Autumn क्यों

**1️⃣ बिलिंग इंफ्रास्ट्रक्चर तेजी से जटिल हो जाता है**

सिर्फ पेमेंट से अधिक: यह परमिशन मैनेजमेंट, मीटरिंग, cron जॉब्स के साथ उपयोग सीमा बनाना, और इसे अपग्रेड, डाउनग्रेड, कैंसिलेशन और फेल्ड पेमेंट स्टेट्स से कनेक्ट करना है। रेस कंडीशन, एज केस और अन्य बग्स आपको धीमा कर देंगे।

**2️⃣ बिलिंग और ऐप लॉजिक को अलग होना चाहिए**

बढ़ती कंपनियां अक्सर प्राइसिंग पर इटरेट करती हैं: कीमतें बढ़ाना, क्रेडिट के साथ प्रयोग करना या किसी नए फीचर के लिए चार्ज करना। DB माइग्रेशन, इन-ऐप फ्लो को फिर से बनाना, कस्टम प्राइसिंग के लिए इंटरनल डैशबोर्ड और पुरानी प्राइसिंग पर यूज़र्स को ग्रैंडफादर करना एक दुःस्वप्न है।


## यह कैसे काम करता है
सबसे पहले, डैशबोर्ड पर अपने प्रोडक्ट और प्लान बनाएं। हम **कोई भी** प्राइसिंग मॉडल सपोर्ट करते हैं। कुछ लोकप्रिय जो हमने देखे हैं उनमें शामिल हैं:

1. **उपयोग और ओवरेज** ⚡: रियल-टाइम उपयोग सीमा सेट करें और चुनें कि वे कब रीसेट हों। यदि यूज़र्स ओवर हो जाते हैं तो उन्हें चार्ज करें।
2. **क्रेडिट** 💰: यूज़र्स मौद्रिक या मनमाने क्रेडिट तक पहुंच सकते हैं जिससे कई फीचर्स ड्रॉ कर सकते हैं
3. **प्रति-सीट सीमा के साथ सीट-आधारित** 👥: ग्राहकों को उनके यूज़र्स (या अन्य एंटिटीज़) के लिए बिल करें
4. **पहले से भुगतान** 💳: यूज़र्स को किसी फीचर की एक निश्चित मात्रा को अपफ्रंट खरीदने दें, जो समय के साथ उपयोग की जाती है


इसके बाद, आपकी सभी बिलिंग लॉजिक केवल 3 फ़ंक्शन्स के माध्यम से लागू की जा सकती है:

1. `/attach`: सभी परचेज फ्लो के लिए एक फ़ंक्शन कॉल। हम एक Stripe Checkout URL रिटर्न करते हैं, या अपग्रेड/डाउनग्रेड को हैंडल करते हैं।

```tsx
const { attach } = useAutumn();
<button
  onClick={async () => {
    await attach({ productId: "pro" });
  }}
>
  Pro में अपग्रेड करें
</button>
```

2. `/check`: चेक करें कि क्या किसी कस्टमर के पास किसी प्रोडक्ट, फीचर या शेष उपयोग तक पहुंच है।
```ts
const { check } = useAutumn();

const { data } = await check({ featureId: "ai_tokens" })

!data.allowed && alert("AI सीमा पहुंच गई")
```

3. `/track`: जब कोई कस्टमर किसी उपयोग-आधारित फीचर का उपयोग करता है, तो एक उपयोग इवेंट रिकॉर्ड करें।

```ts
const { track } = useAutumn();

await track({
  featureId: "ai_tokens",
  value: 1312
})
```
